# Snap 与 CleanShot X 功能差距

调研日期：2026-11-09。本文只做调研，没有改代码。

**来源**
- CleanShot X 官网功能页：https://cleanshot.com/features
- CleanShot X 更新日志：https://cleanshot.com/changelog，看到 5.0.2（2026-10-26）为止
- `cleanshot.com/docs` 返回 404，没能看到帮助文档。所以 CleanShot 那边的交互细节只以功能页和更新日志写到的为准。功能页上 Quick Access 的"Drag & Drop / Quick actions / 临时隐藏"三项，说明文字是从别的板块复制过来的，看不出具体行为。
- Snap 的现状：项目记忆 `snap-project.md`（含二期范围），README，`git log`，以及对 `Sources/` 的逐项 grep。

**难度**
- S：一两天以内，改动集中在一两个文件。
- M：要几天，跨模块或者要新加 UI。
- L：一周以上，或者需要新子系统、外部服务。

**优先级**
- P0：使用频率高、改动小，建议下一步就做。
- P1：值得做，排在 P0 之后。
- P2：可以做，但不急。
- 不做：不建议做，或者需要用户先做决定。

## 1. Snap 已经做到的

| 能力 | Snap 现状 |
|---|---|
| 截图方式 | 区域、窗口、全屏、滚动长截图（手动滚动，纵向）。框选在冻结帧上进行。 |
| 框选辅助 | 十字辅助线、带坐标的放大镜、实时显示像素尺寸。Shift 画正方形，⌥ 从中心向外拉，按住空格移动选区，没开始拖时按空格切到窗口截图。 |
| 窗口截图 | 保留窗口圆角、透明背景，阴影由 Snap 自己画，可以关掉。 |
| OCR | 用 Vision 在本机识别，表格行保留 Tab 分隔。Quick Access 浮层上也能用。 |
| 录屏 | MP4（H.264），帧率 15/30/60，可选是否显示指针。系统声音和麦克风混成一条音轨。可暂停，菜单栏显示计时。能裁剪，能转 GIF。 |
| Quick Access 浮层 | 复制、保存、分享、标注、贴图、OCR、拖出去当文件用。会自动关闭（时间可设），可以滑动关掉，⌥ 点关闭按钮关掉全部。复制后会删掉自动保存的那个文件（82643bc）。 |
| 编辑器 | 箭头、矩形、椭圆、直线、画笔、文字、高亮、像素化、模糊、聚光灯、序号。有选择工具、裁剪、缩放和平移、撤销/重做。 |
| 背景工具 | 渐变、纯色、桌面壁纸，可调边距、圆角、阴影，画布比例 1:1 / 4:3 / 16:9，可套 Mac 窗口或浏览器外框。 |
| 贴图 | 置顶显示，滚动或双指缩放，⌥ 加滚动调透明度，有右键菜单。 |
| 历史记录 | 保留最近 50 张（数量可设），可复制、标注、贴图、拖出、在 Finder 中显示。 |
| 其他 | 打开已有图片或剪贴板里的图来标注或贴图；开机启动；每天检查一次更新；系统分享菜单。 |

## 2. 还缺的功能

按 CleanShot 功能页上的板块分组。每项都写了 CleanShot 怎么做、Snap 现在怎么做、为什么值得加、难度和优先级。

### 2.1 截图

## 3. P0：实现思路和要改的文件

### P0-1　重拍上一次选区 + 选区精调（A1，M）

**交互**
- 拖完选区之后先不截图，选区进入"可调整"状态：
  - 四边和四角出现拖拽手柄；
  - 方向键移动 1pt，⇧ 加方向键移动 10pt，⌥ 加方向键改大小；
  - 尺寸标签可以点开，直接输入宽和高；
  - 回车或双击确认截图，Esc 取消。
- 为了不拖慢现在"拖完就截"的手感，加一个设置项"Adjust selection before capturing"（拖完后先调整），默认关。设置关着的时候，按住某个修饰键松开鼠标，就进入调整状态。
- 新加一个快捷键"Capture previous area"（重拍上一次选区）：冻结屏幕后直接用上一次的选区，进入可调整状态，回车就截。

**要改的文件**
- `Sources/Snap/Overlay/AreaSelection/AreaSelectionView.swift`：加选区"已拖完、可调整"状态，手柄的命中判断和拖动，方向键处理（现在的 `keyDown` 只管 Esc 和空格），尺寸输入框。
- `Sources/Snap/Overlay/AreaSelection/AreaSelectionSession.swift`：`run(snapshots:initialSelection:)` 接收一个预设的初始选区。
- `Sources/Snap/Coordinator/CaptureCoordinator.swift`：记住上一次选区（存显示器 ID 和这块显示器上的局部坐标），再加一个 `.previousArea` 入口。
- `Sources/Snap/Hotkeys/Shortcuts.swift`、`Sources/Snap/MenuBar/StatusItemController.swift`、`Sources/Snap/Settings/SettingsWindow.swift`：加快捷键、菜单项和设置项。
- `Sources/SnapCore/Settings/AppSettings.swift`：持久化上一次的选区和"拖完先调整"开关。
- `Sources/SnapCore/Geometry/SelectionGeometry.swift`：手柄拖动和吸附的几何计算放这里，便于单测（`Tests/SnapCoreTests/SelectionGeometryTests.swift`）。
- `Tests/SnapUISnapshots`：加一张"可调整状态"的截图用例。

**注意**
- 上一次选区所在的显示器如果已经拔掉，就退回成普通框选。
- 显示器缩放比例变了时，按点（point）坐标还原选区。

### P0-2　延时截图（A2，S）

**交互**
- 菜单栏加一个子菜单"Capture After Delay"（延时截图），选项是 3、5、10 秒，再选截图方式（区域、窗口、全屏）。
- 倒计时期间，屏幕角落显示一个不抢焦点的数字倒计时；按 Esc 或点菜单栏图标可以取消。
- 时间到了再冻结屏幕。区域截图是先冻结再框选，所以菜单展开、悬停提示这类状态会被冻在画面里。

**要改的文件**
- `Sources/Snap/Coordinator/CaptureCoordinator.swift`：`start(_:delay:)`，先等待再走现在的流程；倒计时期间 `isCapturing` 保持为 true，防止重复触发。
- `Sources/Snap/MenuBar/StatusItemController.swift`：子菜单。倒计时期间菜单栏图标显示剩余秒数，可以参考录屏时显示计时的做法。
- `Sources/Snap/Support/Toast.swift`：复用或扩展成倒计时浮层（用 `ignoresMouseEvents`，不抢焦点）。这个组件以后录屏倒计时（R1）也能用。
- `Sources/SnapCore/Settings/AppSettings.swift`：记住上次选的延时秒数（可选）。

### P0-3　截图时隐藏桌面图标（A3，S）

**做法**
- 在 ScreenCaptureKit 的过滤器里，把 Finder 的桌面图标窗口（`windowLayer` 等于 `kCGDesktopIconWindowLevel`）和桌面小组件窗口排除掉。壁纸窗口不是 Finder 的，会保留。
- 这样不用改用户的 Finder 设置，也不会有图标闪一下的问题。
- 冻结帧、全屏截图、区域截图、录屏走的都是 `ScreenshotService` 里的过滤器，改这一处全部生效，也就顺带做完了 R4 的一半。

**要改的文件**
- `Sources/SnapCapture/ScreenshotService.swift`：`ownWindows(in:)` 旁边加一个 `desktopClutter(in:)`，`capture(_:excluding:)` 和 `areaFilter` 把它并进排除列表。
- 录屏和滚动长截图也是通过 `areaFilter` 拿过滤器，所以不用再单独改。
- `Sources/SnapCore/Settings/AppSettings.swift` 和 `Sources/Snap/Settings/SettingsWindow.swift`：在 Capture 页加"Hide desktop icons"（隐藏桌面图标）开关，默认关，避免改变现有用户的截图结果。
- `Tests/SnapCaptureTests`：用 `SNAP_INTEGRATION=1` 跑的集成测试里，断言排除列表里有 Finder 的桌面窗口。

**要先验证的点**
- macOS 14、15、26 上桌面图标窗口的 layer 值和所属进程是否一致。小组件窗口归哪个进程（`NotificationCenter` 还是 `WidgetKit` 的某个进程）也要实测确认。

### P0-4　贴图锁定模式 + 方向键移动（P1，S）

**交互**
- 右键菜单和快捷键 ⌘L 切换锁定模式。锁定后：
  - 贴图设成 `ignoresMouseEvents = true`，点击会穿透到下面的 App；
  - 贴图的边框变成虚线，或者在角上显示一个小锁图标，提醒用户现在是锁定状态。
- 锁定后贴图收不到点击，所以解锁要通过菜单栏的"Unlock All Pins"（解锁全部贴图），或者一个全局快捷键。
- 没锁定时，方向键移动 1pt，⇧ 加方向键移动 10pt。

**要改的文件**
- `Sources/Snap/Pin/PinPanel.swift`：在 `keyDown` 里加方向键处理（keyCode 123–126），加锁定状态、锁定时的样式和菜单项。
- `Sources/Snap/Pin/PinController.swift`：维护全部贴图，提供"解锁全部 / 隐藏全部 / 关闭全部"（顺带做掉 P2）。
- `Sources/Snap/MenuBar/StatusItemController.swift`、`Sources/Snap/Hotkeys/Shortcuts.swift`：加入口。

### P0-5　OCR 识别二维码（O1，S）

**交互**
